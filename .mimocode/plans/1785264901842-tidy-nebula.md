# cardigann-go: JSON Sub-selection, Login Form Selector, Query Fields

## Report

**What was built** — Three improvements to cardigann-go:
1. `jsonNode` now implements `SubSelectable` via a `Find()` method using `gjson.Result.Get()`, enabling nested field extraction for JSON-based indexer definitions (e.g., `sub.Find("title")` on a JSON row).
2. `def.Login.Form` is now wired: when set, the login form selector scopes CSRF extraction to the target `<form>` and uses its `action` attribute as the POST URL. `SubmitPath` takes precedence when both are set.
3. Template Query fields (`TVDBID`, `Year`, `Genre`, `DoubanID`, `IMDBIDShort`) are verified accessible via `{{ index .Query "..." }}` with table-driven tests, and documented in the README.

**Verification** — `go test -count=1 ./...` passes all 10 packages. Login: 20 tests (16 original + 4 new). Selector: 7 tests (5 original + 2 new). Template: 6 tests (5 original + 1 new).

**Journey log** —
- Pre-existing bug found: `definition/definition.go` was missing `fmt` import (caught during build, fixed trivially).
- Technical reviewer caught two compile errors in the initial plan (missing `formSelector` argument, early return preventing form action extraction). Both fixed before implementation.
- Design reviewer flagged `__form_action` sentinel key as fragile; replaced with `extractSelectorInputsResult` struct.

## [S1] Problem

Three gaps in cardigann-go prevent gowlarr (and other consumers) from using certain Cardigann v11 definition features:

1. **JSON sub-selection** — `jsonNode` in `selector/selector.go` does not implement the `SubSelectable` interface. When a definition uses `sub.Find()` on a JSON response row (e.g., extracting nested fields like `title`, `link` from each row object), the engine's type-assertion to `SubSelectable` fails silently, and field extraction falls back to the row's raw text/attributes. HTML (`*htmlNode`) and XML (`*xmlNode`) nodes both implement `SubSelectable` already. This blocks any JSON-based indexer definition that relies on nested field extraction.

2. **Login form selector** — The `Login.Form` field (`string`, YAML key `form`) is declared in the `Login` struct at `definition/definition.go:108` and documented in the v11 schema, but the `loginForm()` function in `login/login.go` never reads it. The current implementation always POSTs to the URL rendered from `def.Login.Login` (or `def.Login.SubmitPath`) and extracts CSRF tokens from the entire HTML document. When a login page contains multiple `<form>` elements (common on trackers with registration forms, password reset forms, etc.), this can extract inputs from the wrong form or fail to find the correct `action` URL.

3. **Missing Query field test coverage** — The `Query` struct (`engine/engine.go:29-41`) defines `TVDBID`, `Year`, `Genre`, `DoubanID`, and `IMDBIDShort`, and they are correctly mapped to the template context at `engine/engine.go:145-157`. However, the template test suite (`template/template_test.go`) does not test `{{ .Query.<field> }}` access for any of these fields. This means a regression in the mapping would go undetected, and consumers (gowlarr) cannot be confident these fields work.

## [S2] Design

### Feature 1: JSON SubSelectable

**File to modify**: `selector/selector.go`

**Current state** (lines 110-123):
```go
type jsonNode struct {
    result gjson.Result
}
func (n *jsonNode) Text() string { return n.result.String() }
func (n *jsonNode) Attr(name string) (string, bool) {
    sub := n.result.Get(name)
    if !sub.Exists() { return "", false }
    return sub.String(), true
}
```

**Change**: Add a `Find` method to `jsonNode`:

```go
// Find ré-applique un sélecteur gjson relativement à ce noeud (sous-sélection
// d'un champ à l'intérieur d'une ligne de résultat JSON).
func (n *jsonNode) Find(selector string) ([]Node, error) {
    result := n.result.Get(selector)
    if !result.Exists() {
        return nil, nil
    }
    if result.IsArray() {
        nodes := make([]Node, 0)
        result.ForEach(func(_, value gjson.Result) bool {
            nodes = append(nodes, &jsonNode{result: value})
            return true
        })
        return nodes, nil
    }
    return []Node{&jsonNode{result: result}}, nil
}
```

**Rationale**: This mirrors the logic in `jsonDocument.Find()` (lines 94-108) but operates on the node's `gjson.Result` instead of the raw JSON string. `gjson.Result.Get()` supports the same path syntax, so any gjson path that works at the document level also works at the node level. No new dependencies.

**Semantics**:
- `selector` is a gjson path (e.g., `"title"`, `"links.#.href"`, `"category.#"`)
- Returns `nil, nil` if the path doesn't exist (consistent with `jsonDocument.Find`)
- Arrays are unwrapped into `[]Node` (consistent with `jsonDocument.Find`)
- Single values are wrapped in `[]Node` with one element

### Feature 2: Login Form Selector

**Files to modify**: `login/login.go`

**Current state**: `loginForm()` (lines 83-152) does:
1. Render login path from `def.Login.Login`
2. Override with `def.Login.SubmitPath` if set
3. Set pre-login cookies
4. Call `extractSelectorInputs()` which fetches the login page via GET, parses it as HTML, and extracts values from `SelectorInputs` across the whole document
5. Build form values from `def.Login.Inputs` + extracted values
6. POST to loginURL

**Change**: Two modifications are needed.

#### Modification A: `extractSelectorInputs` signature and form scoping

Change `extractSelectorInputs` to accept a `formSelector string` parameter and return the form action URL separately:

```go
// extractSelectorInputsResult holds the extracted values and optional form action.
type extractSelectorInputsResult struct {
    Values     map[string]string
    FormAction string // non-empty when formSelector matched a <form> with an action attribute
}

func extractSelectorInputs(ctx context.Context, client *http.Client,
    def cmodel.IndexerDefinition, baseURL string, rctx tmpl.Context,
    formSelector string) (*extractSelectorInputsResult, error) {
```

Key changes inside:
- Move the HTML parse + form scope logic **before** the early return for empty `SelectorInputs`. When `formSelector != ""`, the function must parse HTML and extract the form action even if `SelectorInputs` is empty.
- When `formSelector != ""`:
  - Parse HTML via `selector.NewHTMLDocument(body)`
  - `doc.Find(formSelector)` to locate the specific `<form>` element
  - If no match, return error `"login form selector %q matched nothing"`
  - Type-assert the form node to `SubSelectable`
  - For each `SelectorInput`, use `formNode.Find(sel.Selector)` instead of `doc.Find(sel.Selector)` — this scopes extraction to the target form
  - Extract `action` attribute from the form node into `FormAction`
- When `formSelector == ""` — current behavior, whole document

The restructured flow:

```go
func extractSelectorInputs(ctx context.Context, client *http.Client,
    def cmodel.IndexerDefinition, baseURL string, rctx tmpl.Context,
    formSelector string) (*extractSelectorInputsResult, error) {

    result := &extractSelectorInputsResult{Values: make(map[string]string)}

    // Nothing to extract and no form to scope
    if len(def.Login.SelectorInputs) == 0 && formSelector == "" {
        return result, nil
    }

    loginPath, err := tmpl.Render(def.Login.Login, rctx)
    if err != nil {
        return nil, fmt.Errorf("rendering login path: %w", err)
    }
    loginURL := resolveURL(baseURL, loginPath)

    req, err := http.NewRequestWithContext(ctx, http.MethodGet, loginURL, nil)
    if err != nil {
        return nil, err
    }
    resp, err := client.Do(req)
    if err != nil {
        return nil, fmt.Errorf("fetching login page: %w", err)
    }
    defer resp.Body.Close()

    body, err := io.ReadAll(io.LimitReader(resp.Body, 4<<20))
    if err != nil {
        return nil, err
    }

    doc, err := selector.NewHTMLDocument(string(body))
    if err != nil {
        if formSelector != "" {
            return nil, fmt.Errorf("login form selector requires HTML response")
        }
        return result, nil // non-HTML, skip (backward compat when no form selector)
    }

    // Scope to specific form if selector provided
    var scope selector.Node
    if formSelector != "" {
        formNodes, err := doc.Find(formSelector)
        if err != nil || len(formNodes) == 0 {
            return nil, fmt.Errorf("login form selector %q matched nothing", formSelector)
        }
        scope = formNodes[0]
        // Extract form action if present
        if action, ok := scope.Attr("action"); ok && action != "" {
            result.FormAction = action
        }
    }

    for name, sel := range def.Login.SelectorInputs {
        var nodes []selector.Node
        if scope != nil {
            if sub, ok := scope.(selector.SubSelectable); ok {
                nodes, err = sub.Find(sel.Selector)
            }
        } else {
            nodes, err = doc.Find(sel.Selector)
        }
        if err != nil || len(nodes) == 0 {
            if sel.Optional {
                continue
            }
            continue // skip missing selectors gracefully
        }
        var raw string
        if sel.Attribute != "" {
            raw, _ = nodes[0].Attr(sel.Attribute)
        } else {
            raw = nodes[0].Text()
        }
        if sel.Text != "" {
            raw = sel.Text
        }
        if len(sel.Filters) > 0 {
            steps := make([]filters.Step, len(sel.Filters))
            for i, f := range sel.Filters {
                steps[i] = filters.Step{Name: f.Name, Args: f.Args}
            }
            raw, err = filters.Apply(raw, steps)
            if err != nil {
                continue
            }
        }
        result.Values[name] = raw
    }
    return result, nil
}
```

#### Modification B: `loginForm` uses form action

```go
func loginForm(ctx context.Context, client *http.Client, def cmodel.IndexerDefinition, baseURL string, config map[string]string) error {
    rctx := tmpl.Context{Config: config}

    loginPath, err := tmpl.Render(def.Login.Login, rctx)
    if err != nil {
        return fmt.Errorf("rendering login path: %w", err)
    }
    if def.Login.SubmitPath != "" {
        loginPath, err = tmpl.Render(def.Login.SubmitPath, rctx)
        if err != nil {
            return fmt.Errorf("rendering submit path: %w", err)
        }
    }
    loginURL := resolveURL(baseURL, loginPath)

    if len(def.Login.Cookies) > 0 && client.Jar != nil {
        u, _ := url.Parse(baseURL)
        for name, value := range def.Login.Cookies {
            client.Jar.SetCookies(u, []*http.Cookie{{Name: name, Value: value}})
        }
    }

    // Extract dynamic values from the login page (CSRF tokens, etc.)
    extracted, err := extractSelectorInputs(ctx, client, def, baseURL, rctx, def.Login.Form)
    if err != nil {
        return fmt.Errorf("extracting selector inputs: %w", err)
    }

    // If Form selector found a form action, use it as POST target
    // (SubmitPath takes precedence if explicitly set)
    if def.Login.SubmitPath == "" && extracted.FormAction != "" {
        loginPath = extracted.FormAction
        loginURL = resolveURL(baseURL, extracted.FormAction)
    }

    values := url.Values{}
    for name, valueTmpl := range def.Login.Inputs {
        rendered, err := tmpl.Render(valueTmpl, rctx)
        if err != nil {
            return fmt.Errorf("rendering login input %q: %w", name, err)
        }
        values.Set(name, rendered)
    }
    // Merge extracted values (they override static inputs if same key)
    for k, v := range extracted.Values {
        values.Set(k, v)
    }
    // ... rest unchanged (req build, POST, error check, test verification) ...
}
```

**Priority**: `def.Login.SubmitPath` > form `action` attribute > rendered `def.Login.Login`. This ensures backward compatibility: definitions with explicit `SubmitPath` are unaffected.
