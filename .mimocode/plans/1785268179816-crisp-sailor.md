## Changements détaillés

### 1. `engine/request.go` — DRY extraction (NOUVEAU)

**Problème** : La logique de rendu template + séparation `$raw` est dupliquée entre `searchPath()` (L262-279) et `resolveDownload()` (L680-706).

**Solution** : Extraire uniquement le rendu template, PAS la construction GET/POST (qui diffère entre les deux call sites).

```go
package engine

// renderInputs rend tous les inputs via le template et sépare $raw.
// Retourne les inputs rendus et les paramètres $raw bruts.
func renderInputs(inputs map[string]string, rctx tmpl.Context) (map[string]string, string, error) {
    rendered := make(map[string]string, len(inputs))
    var raw string
    for k, v := range inputs {
        if k == "$raw" {
            renderedVal, err := tmpl.Render(v, rctx)
            if err != nil { return nil, "", fmt.Errorf("rendering $raw: %w", err) }
            raw = renderedVal
            continue
        }
        renderedVal, err := tmpl.Render(v, rctx)
        if err != nil { return nil, "", fmt.Errorf("rendering input %q: %w", k, err) }
        rendered[k] = renderedVal
    }
    return rendered, raw, nil
}

// appendRawParams ajoute les paramètres $raw encodés à une url.Values.
func appendRawParams(values url.Values, raw string) {
    for _, param := range strings.Split(raw, "&") {
        if param == "" { continue }
        parts := strings.SplitN(param, "=", 2)
        if len(parts) == 2 { values.Add(parts[0], parts[1]) }
    }
}

// filterInputs supprime les valeurs vides et "false" (truthy dans Go templates).
func filterInputs(rendered map[string]string) url.Values {
    values := url.Values{}
    for k, v := range rendered {
        if v != "" && v != "false" { values.Set(k, v) }
    }
    return values
}
```

**Impact** :
- `searchPath()` : supprimer L262-279 (~17 LOC), remplacer par `renderInputs()` + `filterInputs()`
- `resolveDownload()` : supprimer L680-706 (~26 LOC), remplacer par `renderInputs()`
- Gain net : ~30 LOC de code dupliqué éliminé
- **Pas de risque behavioral** — chaque call site garde sa propre construction GET/POST

**Note** : `resolveDownload()` ne filtre PAS les valeurs vides (contrairement à `searchPath()`). C'est un comportement intentionnel qu'il ne faut pas changer.

```go
package httputil

import "strings"

// ResolveURL résout un chemin relatif/absolue par rapport à une base.
func ResolveURL(baseURL, path string) string {
    if strings.HasPrefix(path, "http://") || strings.HasPrefix(path, "https://") {
        return path
    }
    return strings.TrimRight(baseURL, "/") + "/" + strings.TrimLeft(path, "/")
}
```
